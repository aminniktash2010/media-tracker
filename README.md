# Amin's Media Tracker & Watchlist

An interactive, responsive single-page web application tracking curated movies and prestige TV shows with instant search, category filters, and poster integration.

## Features
- **125 Curated Titles:** Spanning cinema releases, prestige TV (HBO, FX, Apple TV+), arthouse classics, and recent recommendations.
- **Instant Search:** Real-time search across titles, release years, and IMDb IDs.
- **Type Filters:** Quick switching between All, Movies, TV Series, and Newly Added.
- **Watched Tracking:** Check off watched items with automatic browser storage continuity.
- **GitHub Pages Ready:** Self-contained single-page application (`index.html`) ready for zero-configuration hosting on GitHub Pages.

## Deployment to GitHub Pages
1. Push this repository to GitHub (public for free accounts, or private with GitHub Pro).
2. Go to **Settings > Pages**.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your live app will be published at `https://<your-username>.github.io/<repo-name>/`.
